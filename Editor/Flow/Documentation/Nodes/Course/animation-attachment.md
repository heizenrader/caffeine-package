# Animation Attachment

Triggers an animation attachment configured on a course step. Use it to play a step-specific animation as part of a Flow — a reveal, a transition, a feedback motion when the user completes part of a task.

**Category:** Action

## Target

Pick the target step and animation attachment from the inspector dropdowns — the binding is stored automatically on the node.
