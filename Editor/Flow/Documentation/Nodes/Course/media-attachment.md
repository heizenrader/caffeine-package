# Media Attachment

Triggers an interactive media attachment configured on a course step — typically a video, audio clip, or image overlay that's shown or activated as part of a flow.

**Category:** Action

## Target

Pick the target step and media attachment from the inspector dropdowns — the binding is stored automatically on the node.
