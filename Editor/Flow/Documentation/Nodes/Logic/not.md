# Not

Inverts a Bool — outputs `true` when the input is `false`, and `false` when the input is `true`.

**Category:** Variable
**Kind:** Operation

## Inputs

| Port | Type | Description |
|---|---|---|
| input | Bool | The Bool to invert. |

## Outputs

| Port | Type | Description |
|---|---|---|
| output | Bool | The inverse of `input`. |
