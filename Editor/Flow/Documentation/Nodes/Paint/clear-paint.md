# Clear Paint

Clears all paint coverage on the connected Paintable surface, returning it to its initial unpainted state.

**Category:** Action
**Component / Source:** Caffeine `Paintable`

## Inspector parameters

| Field | Type | Description |
|---|---|---|
| paintable | Paintable | The paintable surface to clear. |

:::tip Reset between exercises
Use Clear Paint when the user retries a painting exercise, moves to a different paint step, or you want to wipe progress without reloading the scene.
:::
