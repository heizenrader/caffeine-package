# Create Vector2

Builds a Vector2 from two Float inputs (x, y). Use it for 2D positions, UV coordinates, or any pair of floats that need to flow as a single Vector2.

**Category:** Variable
**Kind:** Constructor

## Inputs

| Port | Type | Description |
|---|---|---|
| x | Float | X component. |
| y | Float | Y component. |

## Outputs

| Port | Type | Description |
|---|---|---|
| output | Vector2 | The assembled Vector2. |
