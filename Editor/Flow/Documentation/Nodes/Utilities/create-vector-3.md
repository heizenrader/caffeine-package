# Create Vector3

Builds a Vector3 from three Float inputs (x, y, z). Use it whenever a node needs a Vector3 and you have the components separately — driving Y by a slider, building a position from height + horizontal coords, etc.

**Category:** Variable
**Kind:** Constructor

## Inputs

| Port | Type | Description |
|---|---|---|
| x | Float | X component. |
| y | Float | Y component. |
| z | Float | Z component. |

## Outputs

| Port | Type | Description |
|---|---|---|
| output | Vector3 | The assembled Vector3. |
