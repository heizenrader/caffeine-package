# Get Parent

Returns the parent Transform of a target Transform — what it's currently parented to in the scene hierarchy.

**Category:** Variable
**Kind:** Property

## Inputs

| Port | Type | Description |
|---|---|---|
| target | Transform | The Transform whose parent to return. |

## Outputs

| Port | Type | Description |
|---|---|---|
| parent | Transform | The parent Transform, or `null` if the target is at the scene root. |
