# Remove GameObject Item (Index)

Removes the GameObject at a specific index from a `List<GameObject>`. Variant that removes by reference: [Remove GameObject Item](./remove-gameobject-item).

**Category:** Action

## Inputs

| Port | Type | Description |
|---|---|---|
| list  | List&lt;GameObject&gt; | The list to remove from. |
| index | Int                     | Zero-based index to remove. Out-of-range indexes are silently ignored. |
