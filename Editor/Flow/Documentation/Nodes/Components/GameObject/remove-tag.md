# Remove Tag

Removes any `EdXR_Tag` components on a GameObject that match the given tag value. Multiple matches are all removed.

**Category:** Action

## Inputs

| Port | Type | Description |
|---|---|---|
| gameObject | GameObject | The GameObject to untag. |
| tag        | String     | The tag value to remove. |
