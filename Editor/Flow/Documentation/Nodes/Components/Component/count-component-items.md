# Count Component Items

Returns the number of components in a `List<Component>`.

**Category:** Variable
**Kind:** Property

## Inputs

| Port | Type | Description |
|---|---|---|
| list | List&lt;Component&gt; | The list to count. |

## Outputs

| Port | Type | Description |
|---|---|---|
| count | Int | The number of elements. Returns 0 if the input is null or unconnected. |
