# Remove Component Item (Index)

Removes the component at a specific index from a `List<Component>`. The variant that removes by reference is [Remove Component Item](./remove-component-item).

**Category:** Action

## Inputs

| Port | Type | Description |
|---|---|---|
| list  | List&lt;Component&gt; | The list to remove from. |
| index | Int                   | Zero-based index to remove. Out-of-range indexes are silently ignored. |
