# Disable AR

Switches the viewer back out of augmented-reality mode, returning to the normal rendered view. The counterpart of [Enable AR](./enable-ar).

**Category:** Action

:::note Only where AR is supported
Has no effect on builds and devices that don't support AR (such as VR builds), and does nothing if AR is already off.
:::

- [Is AR On](./is-ar-on) — check whether AR is currently active
