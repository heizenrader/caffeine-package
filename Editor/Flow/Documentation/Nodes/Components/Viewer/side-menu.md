# Side Menu

Opens or closes the viewer's side menu. Use it to programmatically show or hide the side menu UI from a Flow Graph — for example, opening it at the start of a step that needs the user's attention there, or closing it when entering an immersive sequence.

**Category:** Action / Variable

## Inputs

| Port | Type | Description |
|---|---|---|
| open | Bool | `true` to open the side menu, `false` to close it. |

## Outputs

| Port | Type | Description |
|---|---|---|
| isOpen | Bool | The current open / closed state. |
