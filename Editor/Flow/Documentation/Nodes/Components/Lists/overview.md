# Lists Nodes

List manipulation nodes for typed collections beyond GameObject (which has its own [Add/Get/Count/Remove GameObject Item](/docs/Flow/Nodes/Components/GameObject/add-gameobject-item) family).

## Nodes

| Node | Description |
|---|---|
| [Get String Item](./get-string-item)                       | Return the string at a given index in a `List<String>`. |
| [Get SnapshotFile Item](./get-snapshot-file-item)          | Return the SnapshotFile at a given index in a `List<SnapshotFile>`. |
| [Count SnapshotFile Items](./count-snapshot-file-items)    | Number of entries in a `List<SnapshotFile>`. |
