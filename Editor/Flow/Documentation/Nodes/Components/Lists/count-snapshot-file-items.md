# Count SnapshotFile Items

Returns the number of entries in a `List<SnapshotFile>`.

**Category:** Variable
**Kind:** Property

## Inputs

| Port | Type | Description |
|---|---|---|
| list | List&lt;SnapshotFile&gt; | The list to count. |

## Outputs

| Port | Type | Description |
|---|---|---|
| count | Int | The number of entries. Returns 0 for null or unconnected input. |
