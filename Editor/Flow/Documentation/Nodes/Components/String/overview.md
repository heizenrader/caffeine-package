# String Nodes

String manipulation utility nodes — check for substring matches, get length, convert case, extract a substring.

## Nodes

| Node | Description |
|---|---|
| [String Contains](./string-contains)  | Test whether a string contains any of a list of cases; returns the matched case as well. |
| [String Length](./string-length)      | Number of characters in a string. |
| [String ToLower](./string-tolower)    | Convert a string to all lowercase. |
| [Substring](./substring)              | Extract a portion of a string by start index and length. |

:::tip Build complex strings with Format String
For interpolation and templated output (e.g. `"Score: {0}"`), use [Format String](/docs/Flow/Nodes/Utilities/format-string).
:::
