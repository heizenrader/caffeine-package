# String Length

Returns the number of characters in a string.

**Category:** Variable
**Kind:** Property

## Inputs

| Port | Type | Description |
|---|---|---|
| inputString | String | The string to measure. |

## Outputs

| Port | Type | Description |
|---|---|---|
| length | Int | Character count. Returns 0 for null or empty input. |
