# <span class="net-node">Net OnPlayerExit</span> <span class="net-badge">NET</span>

Fires on every remaining client when a player leaves the multiplayer session. Use it to clean up UI, redistribute roles, or update rosters.

**Category:** Event (Net, Lifecycle)
**Component / Source:** Built-in (multiplayer)

## Outputs

| Port | Type | Description |
|---|---|---|
| Flow | Flow | Kicks on every remaining client when a player exits. |
