# Pulse Stop Airway Obstruction

Clears any airway obstruction on the Pulse patient. Use it as the resolution to a respiratory-distress scenario when the user successfully intervenes.

**Category:** Action

## Inspector parameters

| Field | Type | Description |
|---|---|---|
| patient | EdXR_PulsePatient | The Pulse patient. |
