# Simple Current Date

Returns today's date as a string in long form, e.g. `October 25, 2026`.

**Category:** Variable
**Kind:** Property

## Outputs

| Port | Type | Description |
|---|---|---|
| date | String | Current date formatted as `MMMM dd, yyyy`. |

:::tip Display-only
This node returns the date as a string for display. For comparing dates or computing date arithmetic, use a [Current Time (Clock)](./current-time)'s components or build the value yourself in a script.
:::
